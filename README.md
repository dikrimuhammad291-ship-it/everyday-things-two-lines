An entry for the [make.fun](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479) bounty **Everyday Things, Two Lines, Longer Run**: two lines about an everyday thing — a toaster, compared to a tiny sun.

## How it works

`main.py` (Python 3, standard library only) writes the two lines to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). The program is deterministic and runs offline: two runs produce byte-identical output.

## The entry

> A toaster is a tiny sun trapped in a metal box: it stares at your bread until it turns brown, then pops it up like it is surprised every single time.
>
> The analogy works because both cook with heat and light, but it leaves out the ding, the lever, and the fact that the sun has never burned anyone's breakfast.
